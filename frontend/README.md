
# Facture IA — Nouvelle interface

Ce dossier accueillera la nouvelle interface web personnalisée de Facture IA.

## Objectifs
- Design professionnel noir et or.
- Tableau de bord responsive, adapté aux ordinateurs et téléphones.
- Navigation et composants personnalisés.
- Connexion ultérieure au backend Python existant.

## Règles de migration
- Ne pas modifier app_factures.py pendant cette phase.
- Ne pas modifier la base de données ni les données existantes.
- Utiliser des données fictives pour les premières maquettes.
- Ne jamais exposer de secrets ou de clés Supabase dans le navigateur.
- Conserver l'application actuelle fonctionnelle pendant la migration.
